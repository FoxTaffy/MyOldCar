# MyOldCar — OBD-II сканер и регистратор поездок (по умолчанию ВАЗ 2104, М73)

Vue 3 + Vite + TypeScript + Tailwind + Capacitor. ELM327 (Wi-Fi/Bluetooth LE). Диагностика работает без интернета; интернет нужен только для плиток карты и по кнопкам «адрес»/«найти VIN в NHTSA».

```bash
npm install
npm run dev     # браузер, режим Mock (симуляция ЭБУ, ошибка P0171)
npm test        # движок диагностики, парсеры, расход, замер 0-100
```

## Только чтение
Приложение ничего не пишет в ЭБУ и не сбрасывает ошибки. `ELMService.send()` пропускает только служебные AT-команды адаптера и запросы на чтение (режимы 01, 02, 03, 07, 09, 0A); всё остальное (в т.ч. 04 — сброс, 08 — управление, сервисы записи) отклоняется до отправки. Тесты: `tests/features.test.ts`.

## Запись поездок в фоне
- **Старт и конец автоматические.** Поездка начинается, когда есть активность (обороты > 0, скорость OBD или GPS > 2 км/ч). Если **30 минут** ни один датчик (OBD и GPS) не показывает движения или работы двигателя — поездка закрывается и сохраняется; концом считается момент последней активности. Потеря связи с адаптером поездку не обрывает — запись продолжает GPS.
- **В фоне.** На Android GPS работает через службу переднего плана с уведомлением (`@capgo/background-geolocation`), поэтому процесс и опрос адаптера живут при свёрнутом приложении. При первом запуске приложение само запросит геопозицию, геопозицию «Всегда» и уведомления (нужны, чтобы писать поездку при выключенном экране). Если отказали, на экране поездок будет кнопка «Открыть настройки»; на некоторых прошивках (Xiaomi, Huawei, Samsung) отключите для приложения экономию батареи. Каждую точку служба дополнительно пишет в свой журнал: если Android усыпил интерфейс, приложение дочитывает пропущенное раз в 30 с и при возврате на экран. Редкие точки (раз в 10–60 с, без скорости) тоже идут в зачёт — пробег считается по смещению координат.
- **Карта** — Leaflet + OpenStreetMap (открытая): маршрут окрашен по скорости, `A`/`B`, остановки `P 5:12`, красный **`!`** там, где загорелась Check Engine (с кодами, которые её включили). Тап по линии/ползунок — скорость, обороты, ОЖ, расход, нагрузка, дроссель, напряжение и адрес места (Nominatim, по тапу). Тёмная тема карты — CSS-инверсия плиток.
- Треки хранятся у последних 30 поездок (`localStorage`), прореживаются до 1200 точек на поездку.

## Автомобили и VIN
Вкладка-шапка «название машины ▾» → профили: марка/модель/год, двигатель, объём, мощность, топливо, КПП, бак, одометр, масло, шины, заметки; шаблоны для ВАЗ/LADA. У каждой машины свои поездки, масло и счётчик пробега. VIN: сканирование штрихкода камерой (ML Kit: Code 39/128, Data Matrix, PDF417, QR), чтение из ЭБУ (режим 09 02 — старые К-линейные М73 его часто не отдают), ручной ввод; офлайн-расшифровка (страна, изготовитель, модельный год, контрольная цифра) и опциональный запрос в NHTSA.

## Ошибки
`src/data/dtcDictionary.ts` — справочник на русском: ≈500 универсальных кодов P0xxx/P2xxx (лямбда, форсунки, катушки, пропуски генерируются по семействам), заводские P1xxx для Январь/Bosch M7.9.7, часть B/C/U. Любой считанный код расшифровывается; если его нет в справочнике — описание строится по структуре кода (система, универсальный/заводской, подсистема). Поиск по коду и словам — внизу вкладки «Ошибки». Заводские P1xxx приведены по памяти документации — сверяйтесь с мануалом на ваш блок.

## Структура
- `src/services/ELMService.ts` — AT-инициализация, PID 0C/0D/05/10, режимы 03/04, транспорты (Capacitor TCP, WebSocket, Mock).
- `src/services/DiagnosticEngine.ts` + `src/data/dtcMatrix.json` — экспертная система: у каждой причины базовый вес и декларативные правила (+очки по датчикам/настройкам). Новые правила для «четвёрки» добавляются только в JSON.
- `src/services/PerformanceTimer.ts` — автомат 0–100 + детектор пробуксовки сцепления.
- `src/services/FuelCalculator.ts` — л/ч и л/100 км по ДМРВ (AFR 14.7, ρ=745 г/л).

## На телефоне (APK)
Транспорт для реального адаптера — нативный плагин [`capacitor-tcp-socket`](https://www.npmjs.com/package/capacitor-tcp-socket) (Capacitor 8).
APK собирает GitHub Actions (`.github/workflows/android-apk.yml`): вкладка **Actions → Android APK → последний запуск → Artifacts → MyOldCar-debug-apk**.

Локально (нужны Node 22, JDK 21, Android SDK):
```bash
npm ci && npm run build
npx cap add android && node scripts/patch-android.mjs && npx cap sync android
cd android && ./gradlew assembleDebug   # android/app/build/outputs/apk/debug/app-debug.apk
```
Телефон подключайте к Wi-Fi адаптера (192.168.0.10:35000). Если Android предлагает отключиться из-за отсутствия интернета — оставайтесь в сети.
