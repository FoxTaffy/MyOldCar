# MyOldCar — OBD-II сканер и регистратор поездок (по умолчанию ВАЗ 2104, М73)

Vue 3 + Vite + TypeScript + Tailwind + Capacitor. ELM327 (Wi-Fi/Bluetooth LE). Диагностика работает без интернета; интернет нужен только для плиток карты и по кнопкам «адрес»/«найти VIN в NHTSA».

**Скачать APK:** [последняя версия](https://github.com/FoxTaffy/MyOldCar/releases/latest/download/MyOldCar.apk) — ссылка всегда ведёт на свежую сборку из `main`. Новые версии ставятся поверх установленной (подпись постоянная), а само приложение предложит обновиться (Настройки → «О приложении»).

```bash
npm install
npm run dev     # браузер, режим Mock (симуляция ЭБУ, ошибка P0171)
npm test        # движок диагностики, парсеры, поездки, справочник, замер 0-100
```

## Новое в 0.7
- **Кнопка «Назад»** (Android) возвращает на предыдущий экран и закрывает открытые окна/меню; на главном экране первое нажатие предупреждает, второе (в течение 2 с) сворачивает приложение — запись поездки продолжается.
- **Новичок** видит приветствие с анимацией и обязательно добавляет автомобиль (марка с логотипом → модель → топливо → объём). «Машины по умолчанию» нет. Логотипы производителей лежат в `public/logos` (работают без интернета, нет файла — цветной значок).
- **Адаптер не найден** (далеко от машины, выключен, не отвечает) — автоподключение останавливается и ждёт ручного нажатия «Подключить»; после обрыва связи делается 2 попытки, потом тоже ожидание.
- **Умная мойка** (`/wash`): загрязнённость 0–100 по дням с последней мойки (записи «Мойка» в журнале), пробегу, дождям и сезону соли (ноябрь–март); прогноз Open-Meteo подсказывает не мыть перед дождём и при морозе ≤ −5 °C. Без интернета и геопозиции совет считается по дням и пробегу.
- **«Едем или стоим»** решается по скорости и оборотам вместе (`MotionState.ts`), а не по GPS: дрейф GPS на стоянке с работающим двигателем — это стоянка; мёртвый датчик скорости OBD при уверенном GPS — едем (по GPS); скорость без оборотов — накат. По отношению оборотов к скорости оценивается передача.
- **Карта поездок** (`/routes`): маршруты всех поездок за 7 дней, 30 дней и всё время; для каждой поездки хранится компактный маршрут (≤220 точек), поэтому «всё время» не ограничено 30 последними треками.

## Интерфейс (v0.6)
Светлая тема по умолчанию (есть тёмная и «как в системе»), главный экран с плитками разделов, боковое меню, нижняя навигация.
- **Главная** — карточка машины с кнопкой подключения и тремя настраиваемыми показателями (14 вариантов), живые показания, прогрев, напоминание об обслуживании, сетка разделов. Что показывать и в каком порядке — «Главный экран» в меню.
- **Мониторинг** — круговые плитки датчиков: «+» добавляет (рядом видно текущее значение), карандаш — порядок и удаление; вкладки «Графики» (последние 90 измерений) и «Все датчики».
- **Журнал обслуживания** — расходы по месяцам (заправка / обслуживание / мойка) со сравнением с прошлым месяцем, столбики за полгода, ввод суммы цифровой клавиатурой, литры считаются по цене; средний расход по заправкам с одометром; список расходников с интервалами по пробегу и сроку (масло, фильтры, свечи, ГРМ…), свои позиции.
- **Стиль вождения** — оценки «Безопасность» и «Эко» 0–100 по дням и месяцам; резкие разгоны/торможения, превышения, ночь, обороты. Считается по треку при завершении поездки (`DrivingStyle.ts`), порог превышения настраивается.
- **Топливная эффективность**, **Диагностика двигателя** (8 параметров + среднее по дням за неделю), **Подключение сканера** (тип, протокол, тайм-аут, число попыток, автоподключение), **Разрешения** (статусы и кнопки), **HUD**, **Стоянка**, **Руководство и FAQ**, мастер добавления машины (марка → модель → топливо → объём).
- **Настройки** — тема, размер шрифта, анимации, резервная копия и восстановление всех данных одним файлом.

Не реализовано намеренно: сброс ошибок (приложение только читает), видеорегистратор и платные «данные производителя».

## Только чтение
Приложение ничего не пишет в ЭБУ и не сбрасывает ошибки. `ELMService.send()` пропускает только служебные AT-команды адаптера и запросы на чтение (режимы 01, 02, 03, 07, 09, 0A); всё остальное (в т.ч. 04 — сброс, 08 — управление, сервисы записи) отклоняется до отправки. Тесты: `tests/features.test.ts`.

## Вкладка «Ошибки»
- **Сводка** последнего чтения: сколько подтверждённых и временных кодов, горит ли лампа, по каким системам ошибки, протокол обмена. Результат не пропадает при переходе на другие вкладки; кнопка «Копия» кладёт сводку и расшифровки в буфер обмена.
- **Стоп-кадр** (режим 02): обороты, скорость, температура, нагрузка, коррекции — какими они были, когда ЭБУ записал ошибку. Старые блоки его не отдают — тогда блок просто не показывается.
- Коды читаются и с К-линии, и с CAN (в ответе CAN первым идёт число кодов; длинный ответ приходит несколькими кадрами). Если ЭБУ не ответил (выключено зажигание), приложение так и говорит, а не «ошибок нет».
- Для 77 частых кодов есть оценка причин в процентах (`dtcMatrix.json`); галочки «что недавно делали с машиной» пересчитывают её без повторного чтения. Для остальных — расшифровка и подсказка, с чего начать проверку.

## Запись поездок в фоне
- **Старт и конец автоматические.** Поездка начинается, когда есть активность (обороты > 0, скорость OBD или GPS > 2 км/ч). Если **30 минут** ни один датчик (OBD и GPS) не показывает движения или работы двигателя — поездка закрывается и сохраняется; концом считается момент последней активности. Потеря связи с адаптером поездку не обрывает — запись продолжает GPS.
- **Пробег не теряется.** Если Android усыпил приложение, а служба GPS продолжала писать точки в журнал, после пробуждения эти точки закрывают пропуск — и пробег, и линия на карте. Если датчик скорости машины не работает (OBD показывает 0, а GPS — езду), пробег считается по GPS.
- **Демо отдельно.** Поездки, записанные в демо-режиме, видны только в демо и не идут ни в статистику, ни в счётчик масла, ни в одометр.
- **В фоне.** На Android GPS работает через службу переднего плана с уведомлением (`@capgo/background-geolocation`), поэтому процесс и опрос адаптера живут при свёрнутом приложении. При первом запуске приложение само запросит геопозицию, геопозицию «Всегда» и уведомления (нужны, чтобы писать поездку при выключенном экране). Если отказали, на экране поездок будет кнопка «Открыть настройки»; на некоторых прошивках (Xiaomi, Huawei, Samsung) отключите для приложения экономию батареи. Каждую точку служба дополнительно пишет в свой журнал: если Android усыпил интерфейс, приложение дочитывает пропущенное раз в 30 с и при возврате на экран. Редкие точки (раз в 10–60 с, без скорости) тоже идут в зачёт — пробег считается по смещению координат.
- **Карта** — Leaflet + OpenStreetMap (открытая): маршрут окрашен по скорости, `A`/`B`, остановки `P 5:12`, красный **`!`** там, где загорелась Check Engine (с кодами, которые её включили). Тап по линии/ползунок — скорость, обороты, ОЖ, расход, нагрузка, дроссель, напряжение и адрес места (Nominatim, по тапу). Тёмная тема карты — CSS-инверсия плиток.
- Треки хранятся у последних 30 поездок (`localStorage`), прореживаются до 1200 точек на поездку. Если место в хранилище кончилось, удаляются самые старые треки (цифры поездок остаются), а не настройки и машины.

## Автомобили и VIN
Вкладка-шапка «название машины ▾» → профили: марка/модель/год, двигатель, объём, мощность, топливо, КПП, бак, одометр, масло, шины, заметки; шаблоны для ВАЗ/LADA. У каждой машины свои поездки, масло и счётчик пробега; при смене активной машины идущая поездка закрывается на прежней. Введите показание одометра один раз — дальше приложение показывает его оценку, прибавляя записанные поездки. Масло напоминает о замене и по пробегу, и по сроку (год). VIN: сканирование штрихкода камерой (ML Kit: Code 39/128, Data Matrix, PDF417, QR), чтение из ЭБУ (режим 09 02 — старые К-линейные М73 его часто не отдают), ручной ввод; офлайн-расшифровка (страна, изготовитель, модельный год, контрольная цифра) и опциональный запрос в NHTSA.

## Справочник кодов
`src/data/` — справочник на русском, **1850 кодов**:
- универсальные SAE J2012: P0xxx и P2xxx (топливо и воздух, лямбда-зонды, зажигание, EGR/EVAP, холостой ход, ЭБУ, АКПП и роботы), P34xx (отключение цилиндров), U0xxx (шины CAN, потеря связи с блоками, неверные данные);
- заводские P1xxx для ВАЗ/LADA (Январь 5.1/7.2, Bosch M7.9.7, М73/М74);
- самые распространённые C- и B-коды (ABS, датчики колёс, подушки безопасности) — их трактовка зависит от производителя.

Однотипные коды (датчик: цепь / диапазон / низкий / высокий / перемежающийся; по цилиндрам; по лямбда-зондам) строятся из шаблонов в `dtcData.ts`, остальное лежит текстом в `dtcLists.ts`. Любой считанный код расшифровывается; если его нет в справочнике — описание строится по структуре кода (система, универсальный/заводской, подсистема). К каждому коду есть подсказка «что проверить». Поиск внизу вкладки «Ошибки»: по коду, по началу кода (`P03`) и по нескольким словам (`форсунка 3`, `лямбда подогрев`). Заводские P1xxx приведены по памяти документации — сверяйтесь с мануалом на ваш блок.

## Датчики, поездки, уведомление
- **Датчики** (вкладка): ~20 PID с цветом по зонам — зелёный норма, оранжевый внимание, красный вне нормы; мини-график и шкала зон. Каталог и зоны — `src/data/sensors.ts`. Датчики, на которые ЭБУ не отвечает, скрыты (кнопка «Показать все»).
- **Импорт/экспорт датчиков** (JSON): свой PID режима 01 + формула по байтам A–D (`(A*256+B)/4-40`, без eval) + зоны `ok`/`warn`. Пример — в приложении. Запись в ЭБУ невозможна.
- **Поездки** пишутся автоматически: min/ср/макс и время в каждой зоне по каждому датчику, график поездки (скорость, обороты, ОЖ, напряжение, нагрузка), текстовая сводка и кнопка «Поделиться сводкой».
- **Постоянное уведомление** на Android (в т.ч. Samsung): «машина подключена · работает 12 мин · скорость · ОЖ · В», обновляется раз в 10 с, пока есть связь с адаптером. Реализовано foreground-сервисом (`@capawesome-team/capacitor-android-foreground-service`); манифест и иконку добавляет `scripts/patch-android.mjs` (запускается в CI после `cap add android`; локально запустите его так же). При первом подключении Android 13+ спросит разрешение на уведомления.

## Структура
- `src/services/ELMService.ts` — AT-инициализация и поиск протокола, PID режима 01, коды (03/07), стоп-кадр (02), VIN (09); транспорты: Bluetooth LE, Capacitor TCP, WebSocket-мост (только в браузере), Mock.
- `src/composables/useVehicle.ts` — одно подключение на всё приложение: опрос, переподключение, запись поездки; `useGarage.ts` — машины, поездки и треки в `localStorage`; `useDiagnostics.ts` — последнее чтение ошибок.
- `src/services/DiagnosticEngine.ts` + `src/data/dtcMatrix.json` — экспертная система: у каждой причины базовый вес и декларативные правила (+очки по датчикам/настройкам). Новые правила для «четвёрки» добавляются только в JSON.
- `src/services/TripSession.ts` / `TripRecorder.ts` — объединение OBD и GPS в поездку, автозавершение, трек.
- `src/services/PerformanceTimer.ts` — автомат 0–100 (старт только с места, сорванная попытка сбрасывается) + детектор пробуксовки сцепления; на вкладке хранится история замеров по машинам.
- `src/services/FuelCalculator.ts` — л/ч и л/100 км по ДМРВ (AFR 14.7, ρ=745 г/л).

## На телефоне (APK)
Транспорт для реального адаптера — нативный плагин [`capacitor-tcp-socket`](https://www.npmjs.com/package/capacitor-tcp-socket) (Capacitor 8).
APK собирает GitHub Actions (`.github/workflows/android-apk.yml`): вкладка **Actions → Android APK → последний запуск → Artifacts → MyOldCar-debug-apk**.

Локально (нужны Node 22, JDK 21, Android SDK):
```bash
npm ci && npm run build
npx cap add android && npx cap sync android && node scripts/patch-android.mjs
cd android && ./gradlew assembleDebug   # android/app/build/outputs/apk/debug/app-debug.apk
```
Телефон подключайте к Wi-Fi адаптера (192.168.0.10:35000). Если Android предлагает отключиться из-за отсутствия интернета — оставайтесь в сети.

## Релиз и обновление
Релиз `vX.Y.Z` (версия из `package.json`) с готовым `MyOldCar.apk` публикуется, когда: запушен тег `vX.Y.Z`, или запущен workflow вручную с галочкой `release`, или в сообщении коммита есть `[release]`. Для обновления поверх установленного приложения нужен постоянный ключ: секреты репозитория `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Приложение само проверяет новый релиз (Настройки → «О приложении»).
