# Политика конфиденциальности MyOldCar

_Действует с версии 0.9.0 (ноябрь 2026)._

MyOldCar — приложение для чтения данных автомобиля через адаптер ELM327 и учёта поездок и расходов. У приложения нет своего сервера, учётных записей, рекламы и аналитики.

## Какие данные обрабатываются
| Данные | Зачем | Где хранятся |
|---|---|---|
| Показания датчиков и коды ошибок автомобиля | Диагностика, история ошибок, статистика поездок | Только на телефоне |
| Геопозиция (в т.ч. в фоне) | Запись трека и пробега поездок, погода и умная мойка, место стоянки | Только на телефоне |
| Профили машин, VIN, госномер, расходы, документы и сроки | Журнал обслуживания и напоминания | Только на телефоне |
| Журнал ошибок приложения | Поиск неисправностей | Только на телефоне; отправляется, только если пользователь сам нажал «Отправить» |

Резервные копии (ручные и еженедельные автоматические) хранятся в личной папке приложения на телефоне. Копия уходит за пределы телефона, только если пользователь сам отправил её через «Поделиться».

## Сетевые запросы
Приложение обращается к внешним сервисам только для перечисленных функций. Передаются лишь данные, необходимые для запроса:
- **Плитки карты:** OpenStreetMap; если пользователь указал свой ключ — Яндекс.Карты. Передаётся область карты.
- **Погода:** Open-Meteo; если указан ключ — Яндекс.Погода. Передаются приблизительные координаты.
- **Адрес точки на карте** (по нажатию): Nominatim (OpenStreetMap). Передаются координаты точки.
- **Расшифровка VIN** (по нажатию «найти в NHTSA»): vpic.nhtsa.dot.gov. Передаётся VIN.
- **Проверка обновлений:** GitHub Releases этого репозитория. Персональные данные не передаются.

## Разрешения
- **Геопозиция «Всегда»** — запись поездок при свёрнутом приложении и выключенном экране.
- **Устройства поблизости / Bluetooth** — подключение к BLE-адаптеру.
- **Уведомления** — «Машина подключена», прогрев, напоминания об обслуживании и документах.
- **Камера** — только для сканирования штрихкода VIN.

## Удаление данных
Все данные удаляются вместе с приложением или через «Настройки Android → Приложения → MyOldCar → Хранилище → Очистить». Поездки можно удалить в «Настройки → Удалить все поездки», историю ошибок — на вкладке «Ошибки».
